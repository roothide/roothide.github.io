Procursus (roothide)

Essential Unix tools and libraries for the roothide environment.

This repository provides packages based on Procursus, adapted for use with roothide. It includes command-line utilities, development tools, and the libraries they depend on.

APT Sources

Use main for standard packages. The optional testing component contains experimental packages and uses the same URL and suite. These sources are intended for roothide only.
